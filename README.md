# Film KMM 🎬

Crea tus propias **películas en 3D** con Kamyar, Mami, Norberto y Javier, y míralas como en Netflix. Hecho por **KMM** en Unity.

- 5 escenarios 3D, acciones, diálogos con voz, cámara y música
- 3 películas de ejemplo
- 8 idiomas

## Descargar (Windows)
[Releases](https://github.com/kmaram16/film-kmm/releases/latest) → `Film-KMM-Windows.zip` → descomprime → abre **Film KMM.exe**.
